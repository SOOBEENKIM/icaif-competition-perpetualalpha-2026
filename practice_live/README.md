# 최신 기준시장 자료 → 고정 전략 판단

선택된 **추세＋7일 되돌림 — 하방위험 보정판 (`default`)**에 최신 확정 자료를 공급한다.
기존 `strategy/`, 모델 가중치, 선택된 설정, 과거 데이터·백테스트 결과는 수정하지 않는다.

프로젝트 루트에서 한 차례 갱신하고 판단하려면:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 HF_HUB_OFFLINE=1 .venv/bin/python -m practice_live
```

이 명령은 공개 데이터 수집에 인터넷 연결이 필요하다. 자동 반복 서비스는 시작하지 않는다.
지갑·비밀키를 읽지 않으며, 주문을 생성해 거래소로 전송하는 기능도 없다.

- 자료: Hyperliquid 메인넷의 기존 10개 기준종목 1시간 OHLC·거래량·체결 건수·확정 펀딩.
- 시각: `times`는 봉 시작, `known`/`market_times`는 봉 종료 시각. 종료되지 않은 봉은 제외한다.
- 검증: 모든 종목의 시간 연속성과 펀딩 관측을 요구한다. 누락을 0 또는 직전 값으로 채우지 않는다.
- 연결: 직전 저장 봉·펀딩을 다시 조회하여 정확히 대조한다. 과거 값이 바뀌면 중단하고 원본을 보존한다.
- 판단: 수정하지 않은 `strategy.load_agent("default")`의 `prepare_history`를 호출한다.
- 보존: 기존 5,006개 시점의 입력과 목표 비중을 정확히 재현하고, 보존 대상 파일 해시를 확인한다.
- 게시: 성공한 실행만 `latest.json`에 게시한다. 읽는 쪽도 `completed_bar_utc`가 현재 최신 완료 시간봉인지 확인해야 한다.

`updates/<UTC 실행시각>/`에는 원시 응답·조회 조건·수신 시각(`receipts/`), 검증 기록(`manifest.json`,
`verification.json`), 병합 입력(`inputs.npz`), 모든 시간대 목표 비중(`targets.npz`), 최신 판단
(`signals.json`, `targets_latest.csv`)을 보관한다. 새 실행은 마지막으로 게시된 자료에서 이어 받는다.

`signals.json`의 비중은 **계좌·거래소 실행 제약을 적용하기 전 전략 목표**이다. 실제 보유 비중,
실제 체결, `par` 시장의 현재 가격에 따른 주문 수량을 의미하지 않는다. 정상 리밸런싱은 기존대로
한국시간 03·09·15·21시이며, 시간별 최신 입력·목표와 마지막 정상 판단 시점을 구분해 기록한다.

Chronos-2 공개 사전학습 가중치, 저장된 고정 레짐 모델, 전략 규칙·규모는 그대로 사용한다.
기존 `prepare_history`는 과거 보조 계산을 재실행하지만 선택된 전략의 고정 학습값을 새 자료로
교체하거나 성과에 맞춰 다시 고르지 않는다. 이번 출력은 최신 입력에 대한 판단이며 수익성 검증 결과가 아니다.

오프라인 데이터 검증 테스트:

```bash
.venv/bin/python -m unittest practice_live.test_refresh -v
```
