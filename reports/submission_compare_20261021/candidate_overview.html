원래 전략과 후보의 관계

기본 전략은 mainnet 참조 시장의 완료 봉과 펀딩을 받아 추세·캐리 신호를 만들고, JM 국면·Chronos 예측에 따른 조정, 위험·규모 배분, 7일 되돌림 혼합을 거쳐 최종 비중을 계산합니다. 현행 default는 마지막에 고정 축소 배율을 적용합니다.

별도로 BTC/ETH·BTC/HYPE 페어 전략이 상대가격 예측과 거래비용을 이용해 진입·유지·청산을 판단합니다. 기본 전략과 페어는 공유 계좌와 위험 한도 안에서 PAS에 주문합니다. 이번 후보는 기본 목표 비중에만 적용하며 페어 정책을 변경하지 않습니다.

기존 기본 전략 목표 → 이번 후보 × 1.441173728 → 기존 수량 계산·위험 한도·주문 규칙 → PAS
기존 페어 전략 → 같은 공유 계좌·위험 한도

위 흐름은 후보를 연결할 위치를 설명한 것입니다. 현재 실행 프로세스는 아직 이 어댑터를 import하지 않습니다.

무엇을 어떻게 바꿨나

strategy/profiles.json에서 현재 total_scale은 0.6495940879913923, 원래 설정은 0.9361779335877263입니다. 현재 값은 원래의 0.6938788714042263배이므로 역수 1.44117372816997을 적용합니다. 수익이 커지는 배율을 탐색해서 고른 숫자가 아니라 기존 두 설정의 비율입니다.

부호와 0은 그대로 유지됩니다. 이 변경만으로 새로운 숏 신호가 생기지는 않습니다. 기존에 0이던 종목도 그대로 0입니다. 어댑터는 10종목 마지막 축과 유한한 값을 검사하고, 실제 주문 가능 수량·상한은 후단 실행기가 판단합니다.

"""Offline target adapter for the original-size submission candidate.

The user allocation, reserve, pair strategy and execution risk caps stay the
same. This module is not imported by either running competition service.
"""
import numpy as np

MULTIPLIER=1.44117372816997


def transform(default_weights):
    weights=np.asarray(default_weights,float)
    if weights.shape[-1:]!=(10,) or not np.isfinite(weights).all():
        raise ValueError('Expected finite targets for ten assets')
    return weights*MULTIPLIER
