개선 후보: 모델 재계산과 42개 계좌 재현

유지한 24시간 페어 예측·진입 선별 후보의 결과가 재현됐다. 과거 입력에서 직접 예측과 526개 일별 진입 모델을 재계산해 모든 매핑 필드가 같음을 확인했다. 작업 폴더 밖 /tmp에서 격리된 Python 경로로 실행해 원래 프로젝트의 모듈을 우연히 찾는 의존성도 제거했다.

42개 계좌의 당시 실행 버전 기록을 모두 정확히 재현했다. 별도로 같은 후보 실행 엔진에 기존 전략을 넣었을 때도 실제 체결·계좌 평가·수수료·펀딩·일별 수익률·손익·Q가 모두 같았다. 과거 버전 사이에 달랐던 미체결 주문 의도 기록은 차이 목록에 남겼으며, 이를 전체 기록 일치로 숨기지 않았다.

기본 명령이 페어 모델을 다시 학습한다. --cached-models를 붙이면 고정된 모델 상태로 계좌 재생만 한다. requirements.txt는 검증에 사용한 Python 3.11 환경의 패키지 버전을 기록한다. 별도 새 환경에서 패키지를 설치하는 절차 자체는 실행하지 않았다.

기존 첫째·둘째의 당시 목표 비중을 고정된 비교 입력으로 사용한다. 이 묶음이 기존 Chronos 기준 모델 전체를 처음부터 재훈련한다고 주장하지 않는다. 모든 소스·입력·원래 결과의 해시와 출처를 포함했고, 네트워크 호출과 하위 프로세스 실행을 금지한 상태로 검증했다. 실거래·서명·배포 명령은 없다.

확인한 범위와 남은 문제

기준시장 백테스트 개선과 재현은 확인됐다. 실제 par 호가에서 이 개선 후보가 진입부터 청산까지 수익을 냈다는 증거는 아직 없다. 단기 과거 호가의 비용 조건과 계좌 평가 가능 범위를 확인했으며, 별도 미래 평가 계획은 보존했다. 이 한계를 공식 제출 금지 조건으로 취급하지 않는다.

다음 성능 실험은 현재 24시간 모델을 보존한 채 같은 비용 학습 방식을 72시간 예측에 적용할 근거를 점검하는 것이다. 같은 두 페어·자본·위험 한도를 유지하고, 만기·펀딩·보유 규칙을 먼저 감사한 후 하나의 후보로 고정한다. 여러 만기를 사후 탐색하거나 미래 평가 계획을 바꾸지 않는다.
