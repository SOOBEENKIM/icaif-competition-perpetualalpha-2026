PAS 자동 증거금 레버리지 연결 완료

교체: 2026-10-26T17:17:49+09:00

본대회 실거래 실행자 연결 및 정상 운용 확인 완료. 기존 전략의 방향·목표 수량·위험 제한은 그대로이며, 주문 직전에 필요한 증거금 배수만 자동 계산함. 연구용 수량 확대 모듈은 연결하지 않았음.

동작

우리·팀원 장부를 각각 계산하고, 다른 종목의 설정을 유지한 상태에서 현재 주문에 필요한 최소 정수 배수를 1~3배에서 선택함. 각 소유자 자산의 80%를 증거금 예산으로 삼고, 거래소 허용 최대 배수도 적용함. 기존 예산 초과 상태에서는 이를 악화하지 않는 감축은 허용함. 팀원이 해당 종목을 보유하면 공유 배수를 바꾸지 않음.

배수 변경이 필요하면 계좌를 다시 확인하고 API 설정 변경·확인을 거친 뒤, 원래 주문 수량에 대한 거래소 주문 가능 수량 검사를 통과해야 주문함. 물리적 reduce-only 주문은 배수 변경 절차를 거치지 않음. 조회·변경·확인 기록은 런타임 leverage_events.jsonl에 남김.

최소 증거금을 만족하는 배수 선택이며 미래 PnL의 최적 배수 추정이 아님. 현재 총량 한도는 우리 자산의 60%이므로 통상 1배로 충분함. 같은 수량에서 배수만 높여 가격 손익이 커지지는 않음. 거래소 증거금 규정

검증

  • 48개 검사 통과. 실주문 직전 연결 경로에서 수량 유지·배수 선택·설정 확인 및 reduce-only 우회 검사 포함.
  • 이전 실행자 종료 후 새 실행자 시작. 이전 scored-live 서비스는 inactive. 새로운 상태 기록에서 running, orders_enabled=true, signal_error 없음, fatal 없음 확인.
  • 교체 전후 우리·팀원 보유 수량 동일. 우리 체결 수 48 → 48. 교체 과정에서 거래소 배수 변경 0건.
  • 모델·신호·포트폴리오·위험 한도·주문 수량 산정 소스와 설정 해시 동일. 포지션, 체결 원장, 마지막 판단 시각은 초기화하지 않았음.

팀원 외부 프로그램이 자체 주문을 넣는 구조는 그대로임. 공유한 종목을 보호하고 설정 변경 직전/직후 대조하지만 외부 프로그램과 완전한 동시 잠금이 되는 것은 아님.

복구

rollback 폴더에 이전 코드·설정과 교체 직전 기록을 보존했음. 복구 시 실행자를 멈춘 뒤 코드·설정만 되돌리고 현재 체결 장부를 재대조해야 함. 거래가 재개된 뒤 예전 coordinator·ownership·dispatch 스냅샷으로 계좌 상태를 되돌리면 안 됨.
