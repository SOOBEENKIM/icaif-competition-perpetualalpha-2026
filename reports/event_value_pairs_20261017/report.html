par와 검증 범위

전체 par 기간은 캔들·펀딩과 조건부 체결 모형으로 평가했다. 새 페어 체결은 모두 0건이어서 혼합 후보는 해당 기존 전략과 같은 성과였다. 실제 호가 전체 이력이 확보된 결과가 아니므로 0건을 실제 체결 불가능의 증거로 삼지 않는다. 앞서 관측한 호가 구간에는 원래 페어 신호가 없었고, 이번 후보는 그 신호를 늘리지 않았으므로 새 실제 호가 수익 근거를 만든 것이 아니다.

핵심 검사 7개 통과. 실제 입력을 9월 이전으로 잘라 다시 계산했을 때 과거 신호와 9월 학습 결과가 같았다. 학습 종료 시각과 같은 시각에 완성된 목표도 제외했다. 기존 다섯 대조군의 체결과 계좌 이력은 모든 시장·기간·비용 조건에서 정확히 같았다. 보호된 실거래 소스 373개와 예약 의존 파일 345개는 변경하지 않았다.

모든 자료는 이전 개발에서도 사용한 과거 자료다. 후보 대표를 8월 결과로 고정한 후 이후 계좌 재현을 수행한 순서는 지켰지만, 이를 독립적인 미사용 검증이라고 부르지 않는다. 완성된 미래 호가를 과거로 대체하지 않았으며 실제 주문도 보내지 않았다.
