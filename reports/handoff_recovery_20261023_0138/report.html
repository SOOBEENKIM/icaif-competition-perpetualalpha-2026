재발 방지 코드와 검증

  • 확정된 체결 조회 결과를 재사용해 주문 확인 직후 동일 이력을 다시 조회하는 호출을 제거했습니다.
  • 공개 조회 클라이언트에 공유 요청 예산과 429 대기를 추가했습니다. 조회 실패 후에는 저장된 체크포인트와 확정 체결을 다시 대조한 뒤에만 실행 흐름을 이어가도록 했습니다. 불명확한 주문 결과는 자동 재전송하거나 임의로 지우지 않습니다.
  • 실제 중단 체크포인트 복구, 반복 복구 시 중복 반영 방지, 소유자·수량·가격·수수료 검증, 팀원 보유분 보존, 조회 실패 뒤 재연결, 공유 지갑 대조를 포함한 45개 테스트가 통과했습니다.
  • 적용 후 기본 인계 로더, 배포 파일 무결성, 수량·손익·수수료·펀딩 보존 검사를 통과했습니다. 저장 파일 권한은 0600입니다.

API 예산은 이 클라이언트를 사용하는 프로세스 사이에서 공유됩니다. 다른 프로그램의 요청으로 발생할 수 있는 429까지 없어진 것은 아닙니다. 관련 수정 코드는 다음 주문 실행자 시작 때 사용됩니다. 현재 주문 서비스는 기존 실패 상태(MainPID=0), 신호 생산 서비스만 실행 중입니다.

개선 후보 pullback_any3는 아직 연결하지 않았습니다. 현재 보존된 전략 설정은 all_market_signed_core_v1입니다. 실제 교체 시 최신 체결·보유량과 첫 주문을 다시 검증해야 합니다.
