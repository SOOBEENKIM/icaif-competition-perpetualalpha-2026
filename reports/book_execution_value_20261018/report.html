실제 호가 기반 체결·정리 비용 예측

실제 수신 호가에서 체결 상태·보유 수량·추가 비용을 예측하는 모델은 단순 과거 평균보다 개선됐다. 기존 예측과 연결한 주문 선택에서는 비용을 넘는 신호가 없어 추가 PnL 개선은 확인하지 못했다. 기존에 성과가 개선된 기준시장 후보는 유지한다.

어떻게 달라졌는가

캔들 거래량으로 가상의 체결 가능량을 정하는 대신, 허용된 과거 호가 5개 기록의 실제 잔량과 수신 시각을 사용했다. 앞 2개로 학습하고 3번째에서 모델 채택 기준을 저장했다. 이후 설정을 바꾸지 않고 앞 3개로 다시 학습해 뒤 2개를 평가했다. 과거에 이미 연구한 자료이므로 새 독립 미래 검증이 아니다.

각 시점에서 120k 상한과 동일 위험 한도 아래 실제 호가 잔량의 25/50/100% 크기, 현재 체결 예상가 대비 0/10bp 가격 제한을 비교했다. 양쪽 주문은 별도로 도착한다. 한쪽만 체결되면 같은 제한가로 한 번 보완하고, 실패하면 비용을 내고 정리한다. 관찰은 최대 60초이며, 확인되지 않은 주문·미정리 잔량은 불확실 상태로 보존했다. 펀딩 경계를 넘는 관측되지 않은 지급을 만들지 않았다.

균형 진입 성공은 장기 거래 완료가 아니다. 성공 시에는 실제 보유 비율과 원래 호가 대비 추가 진입 비용만 학습한다. 실패 후 정리된 경우에만 확인된 현금 손실을 비용으로 사용한다. 우연한 불균형 포지션 이익을 비용 감소로 보상하지 않는, 비음수 실행 위험 모형이다. 미확인 현금 결과를 0으로 만들지 않았지만 비용 회귀가 정리 완료 사례에 조건부라는 한계는 남는다.

가상 사례 20,046개는 서로 다른 시각 268개의 방향·수량·지정가·실행 조건 변형이다. 서로 독립적인 20,046건의 실거래가 아니다. 학습 가중치는 같은 시각의 변형들이 합계 1이 되도록 했다.

분리한 기간의 예측 결과

작을수록 좋은 오차 지표다. 비교 대상은 학습 구간의 상태 비율·평균 수량·평균 비용이며, 뒤 기간의 평균을 사용하지 않았다. Brier 점수는 정확도 비율이 아니다.

전략과 연결한 결과

기존 cash_direct 예측과 decisiongate 예측을 모두 그대로 유지했다. 최대 수량, 수량만 최적화, 과거 평균 실행 위험, 새 실행 위험 모델의 네 가지 선택 방법을 비교했다. 원래 가격 예측·헤지·순이익 문턱을 바꾸지 않았다. 이전 호가 판단 272개를 그대로 재현했다.

decisiongate는 검사한 시각에서 신규 진입 방향을 허용하지 않았다. 방향 필터가 없는 cash_direct도 세 가지 수량의 4,536개 판단 중 비용을 넘는 주문을 만들지 못했다. 따라서 새 체결 모델 때문에 거래가 늘거나 PnL이 개선됐다고 주장할 수 없다. 아래는 서로 겹치는 시각·양 방향·수량·기본/불리 조건의 판단 개수다.

최대 수량 후보가 작은 수량 후보와 우연히 같은 주문이 되더라도 비교 대상에서 사라지지 않도록 후보 중복 처리도 보완했다. 앞선 방향 필터 전용 실행과 두 예측을 모두 비교한 실행에서 실제로 선택된 주문은 모두 0개였다. 이 짧고 단절된 호가 기록에는 전체 전략 수익률이나 공식 Q를 붙이지 않는다.

다음 판단

실행 예측 모델은 개선된 연구 구성요소로 보관하되, 실행기만 계속 바꿔 원래 없던 가격 예측 이익을 만들려 하지 않는다. 기존 두 암호화폐 페어 외의 후보를 검토할 때는 평가 전 기간의 자료로 정하는 객관적인 페어 구성 규칙부터 고정한다. 이미 본 손실 때문에 특정 페어만 수동 제거한 뒤 독립 검증이라고 주장하지 않는다. 기존 개선판의 기준시장 +25,868.79 / Q 0.30858은 유지되며, 새 모형의 실거래 성과와는 구분한다.

관련 검사 11개와 기존 호가 판단 대조 272개를 통과했다. 실거래 주문·전략 교체·보류된 미래 자료 열람은 없다.
