주별 제외 재학습과 계좌 연속 운용 비교

보존한 페어 개선판을 유지한다. 새 안정성 필터는 기존 개선판과 14개 평가 조건에서 주문·체결·잔고·손익이 모두 같았다. 추가 수익을 만들었다고 주장하지 않는다. 대신 8월 1일부터 10월 15일까지 계좌를 초기화하지 않은 재평가와, 과거에 고정한 위험 규모를 적용한 비교에서도 보존한 개선판이 기존 1·2번보다 높은 PnL과 Q를 보였다.

초기자본 1M, 외부 기준시장 과거 자료와 모의 체결 비용·수수료·펀딩을 적용한 계좌 결과다. 기간 경계는 모두 12UTC(한국시간 21시)이며 미청산 포지션 평가손익을 포함한다. 실제 par 지갑 수익이나 독립 미래 검증 결과가 아니다. 실제 운용과 예약된 미래 평가 자료는 변경하지 않았다.

새로 구현한 판단

앞선 모델은 청산손익 추정이 음수이면 바로 진입을 막았다. 이번에는 각 적합 시점에 학습 가능한 자료에서 UTC 월요일 기준 한 주씩 제외해 재학습했다. 해당 주와 겹치는 거래는 시작 주가 달라도 모두 제외했다. 원래 모델과 모든 제외 재학습 모델이 음수를 예측할 때에만 기존 진입을 막는다. 최소 네 주와 모든 재학습의 표본 조건이 갖춰지지 않으면 기존 판단을 유지한다. 이는 학습 자료에 대한 부호 안정성 검사이며 수익 확률이나 보장된 신뢰구간이 아니다.

117개 일별 모델 묶음 중 89개가 모든 조건을 갖췄고, 주별 제외 재학습 895개를 완료했다. 8월 BTC/ETH의 원래 음수 추정은 제외 주에 따라 양수로 바뀌었다. 9월 18일 BTC/HYPE도 마찬가지였다. 이 규칙은 앞선 필터가 놓친 수익 진입을 복구했지만 앞선 필터가 피했던 손실 진입도 함께 허용하여, 최종 계좌 경로는 기존 개선판과 같아졌다.

기존 기간별 판정과 par

새 후보는 8월 기본·불리한 조건에서 기존 개선판과 PnL·Q가 같아 추가 승격되지 않았다. 9월 이후 및 par의 여덟 조건에서도 같은 경로다. 이후 연속 운용 결과로 이 결정을 다시 고르지 않았다. 앞선 청산손익 필터는 연속 기본 조건에서 −107.42 낮고 불리한 조건에서는 +336.88 높아, 모든 조건에서 더 좋은 대안은 아니다.

허용된 과거 호가 테이프 다섯 개에서 기존 두 페어 모델과 새 필터 모두 진입 0개였다. 기존 호가 판단 요약 20개를 정확히 재현했다. 이로부터 실제 par에서 완료된 페어의 수익성을 주장하지 않는다.

다음 연구 방향을 바꾼 자료 점검

기존 par 직접 예측 모델을 확인하니 출발 시점 거래량은 요구하지만 학습 목표의 다음 봉 진입가와 미래 종료가에는 실제 거래 발생을 요구하지 않았다. 다음은 원래 학습 조건에 포함된 관측 중 양쪽 종목이 해당 봉에서 모두 거래된 개수다. 봉 거래가 있어도 실제 호가 잔량이나 우리 주문의 체결을 보장하지 않는다.

미래에 거래가 있었던 표본만 골라 학습한 뒤 그 유동성이 항상 있을 것처럼 추론하면 또 다른 편향이 생긴다. 다음에는 실제 par의 역사적 모의 주문 결과를 전량 미체결, 부분 체결, 비용을 지불한 청산 완료, 관측 종료까지 미청산으로 나누어 학습 목표를 만든다. 미래 호가를 꾸며내거나 관측되지 않은 청산을 이익으로 기록하지 않는다. 기존 자료를 사용하는 연구를 계속하되 이 부호 필터의 임계값만 반복 조절하지 않는다.

검증

새 계좌 재생 26개(구간별 후보 12, 연속 계좌 10, 고정 위험 배율 4), 기존 계좌 재현 24개, 검사 8개를 완료했다. 14개 후보 조건의 실제 주문·체결·의사결정·잔고·손익이 기존 개선판과 정확히 같다. 895개 제외 재학습에서 삭제 구간과 겹치는 정답이 남지 않았고 모든 학습 결과가 적합 시점 전에 끝났음을 확인했다. 보호 소스 373개, 예약 의존 345개, 향후 평가 소스 1,045개의 해시도 확인했다. 실제 주문은 보내지 않았다.
