par 체결 후 순손익 학습 비교

결론: 새 6시간·24시간 모델은 기존 계좌 대비 PnL과 Q의 추가 개선을 확인하지 못했다. 기존에 개선된 기준시장 decisiongate 후보는 유지한다. 과거 자료를 반복 사용한 개발 평가이며 실거래나 독립적인 미래 검증이 아니다.

이전 가격 목표는 양 종목의 다음 캔들과 만기 캔들에 거래가 없어도 마지막 가격을 사용했다. 이번에는 같은 과거 par 자료에서 진입·한쪽 체결·한 번의 보완·유료 정리·실제 펀딩을 모의 실행하고, 실제로 포지션이 0이 된 뒤의 순손익을 학습했다. 전량 미체결은 관측된 0, 끝까지 미정리된 건은 검열 자료로 구분했다. 6시간·24시간 고정 보유, 원래 지정가 유지, 위험 한도 유지다.

입력은 당시 알려진 가격 괴리·수익률·거래량·펀딩·헤지 특징, 방향 상호작용과 주문 규모다. 7일 학습창, 3일 가중 반감기, 고정된 5회 학습 시각의 릿지 모델이다. 비용 차감 후 목표이므로 기본 수수료와 펀딩을 이중 차감하지 않는다. 불리한 조건에서는 추가 왕복 비용 26bp만 반영한다. 규칙과 자료를 먼저 고정했고, 10월 8~12일에서 선정을 저장한 뒤 12~16일, 12~17일을 비교했다. 마지막 두 구간은 겹친다. 시각은 UTC 12:00 경계다.

호가 대신 캔들 거래량을 사용하는 체결 모형은 실제 과거 주문장 전체를 재현하지 못한다. 종료 시 남은 포지션은 평가손익이며 무료 청산을 가정하지 않았다. 양 방향·보유기간의 경로는 중복되므로 독립 표본으로 세지 않는다.

자료와 검증

초기 대조 중단은 기존 주문 로그에 없던 entry_limit_blocked 필드 때문이었다. 원래 실행기도 가격 한도를 넘으면 체결 가능 수량을 0으로 만들었다. 추가 필드만 별도 집계하고 모든 공통 주문 필드·체결·계좌·판단·성과의 일치를 확인했다. 가격 제한에 걸렸다고 기록된 건은 두 기록 모두 체결량과 수량 한도가 0임을 검사했다. 학습 결과·모수·선정 규칙은 바꾸지 않았다.

실제 과거 호가 점검

허용된 과거 호가 5개 구간에서 독립적인 진입 점검 12회를 했다. 같은 진입을 재현한 뒤 보완과 유료 정리를 관찰한 결과, 양쪽 진입 2회, 진입 실패 후 유료 정리 6회, 전량 미체결 4회였다. 새 순손익 모델의 6시간·24시간 설정은 동일한 시장 기회 1개를 선택했고 모두 정리 손실이 발생했다. 설정별 결과를 서로 다른 기회로 세면 안 된다. 두 정상 진입은 가격 목표 비교 모델의 결과다. 어느 경우에도 6시간·24시간 만기 청산은 관측되지 않았으므로 이 호가 점검의 수익률이나 Q를 만들지 않았다.

호가 점검은 실제 수신 지연·한정된 잔량·독립된 양쪽 도착을 사용한다. 한쪽 체결 시 원래 지정가로 한 번만 보완하고 실패하면 실제 반대 호가로 정리한다. 캔들 모델의 예측값을 호가 비용에 재보정한 성과라는 주장은 아니다.

유지되는 기존 개선 성과

별도 기준시장 8월 1일~10월 15일 연속 평가에서 기존 첫째 +13,490.84 / Q 0.23534, 둘째 +11,858.42 / Q 0.22507, 유지 후보 +25,868.79 / Q 0.30858이다. 이 표 위의 짧은 par 결과와 서로 다른 기간·시장이다. 새 실험의 실패가 기존 개선을 취소하지 않는다. 표본 수와 내부 후보 선정 조건은 공식 제출 금지 요건이 아니다.

다음 검토

진입 실패 후 정리 비용이 많은 경로를 대상으로, 당시 알 수 있던 거래 활동의 지속성·두 종목의 수량 단위와 헤지 비율·미정리 표본 편향을 먼저 진단한다. 이후 비선형 모델 또는 체결 성공과 조건부 손익을 나누는 모델을 고정해 비교한다. 실거래 주문·전략 교체는 하지 않았다.
