일별 얕은 트리와 회귀·트리 혼합 비교

트리는 8월 성과를 개선했으나 이후 구간에서 유지하지 못했다. 두 새 후보 모두 채택하지 않는다. 새 계좌 재생 32개, 기존 회귀 계좌 경로 대조 4개, 인과성·혼합·저장 모델 테스트 6개를 완료했다. 실거래 주문과 전략 교체는 없다.

구현

BTC/ETH와 BTC/HYPE를 따로 학습한다. 매일 00시 UTC에 최근 90일 중 이미 24시간 목표가 완성된 자료만 사용한다. 입력은 기존 가격 신호 그대로이며, 30일 반감기·6시간 학습 표본·최소 200행·목표 범위 제한도 같다. 트리는 깊이 2, 80회, 학습률 0.04, 최소 자식 가중치 40, L2 10으로 기존 고정 트리의 설정을 가져왔다. 새로운 차이는 최근 자료로 매일 다시 학습하는 점이다. 혼합은 회귀 50%·트리 50%로 고정했다.

트리의 표본 가중치는 행 수 합계로 맞춘다. 최소 자식 가중치 40은 독립 표본 40개를 뜻하지 않으며, 겹치는 24시간 목표로 학습한다. 트리 잎의 규제와 회귀 계수의 규제는 동등한 값이 아니다. 변경 범위는 예측 학습기와 그 고정 혼합이며 매매 규칙·규모·위험 한도·비용은 유지했다.

왜 방향을 맞혀도 수익이 나지 않았는가

이후 BTC/HYPE의 일별 진단에서는 트리가 43개 중 27개의 방향을 맞혔다. 이것은 실제 체결 거래의 승률이 아니다. 비용 조건으로 선택된 진입과 갱신은 다른 시점·수량을 사용한다. 실제 계좌 경로의 해당 페어는 기본 조건에서 가격 이익 +1,395.48에 비해 가격 불이익·수수료가 합계 4,136.08이었다. 방향뿐 아니라 움직임의 크기와 거래 횟수가 비용을 감당해야 한다.

다음 검토

단순 50:50 혼합을 채택하지 않는다. 다음에는 트리의 예상 수익 크기를 이미 발행했던 예측과 나중에 확정된 실제 수익으로 보정할 수 있는지 시험한다. 같은 학습 표본에 다시 예측한 적합값을 보정에 쓰지 않고, 당시 사용 가능했던 모델의 예측만 사용해야 한다. 기존 고정 모델의 잔차·기울기 보정과 먼저 대조하고, 방법과 계수는 이후 평가 전에 고정한다. 이것도 개선이 보장되는 변경은 아니며, 기존 회귀 후보와 실제 운용을 유지한다.

공식 XGBoost 문서에서 가중치·초기값·규제의 의미를 확인했다. 설치된 3.2.0의 저장·재로딩과 실제 예측은 로컬 테스트로 확인했다. 이번 실험은 특정 논문의 성과를 재현했다고 주장하지 않는다.
