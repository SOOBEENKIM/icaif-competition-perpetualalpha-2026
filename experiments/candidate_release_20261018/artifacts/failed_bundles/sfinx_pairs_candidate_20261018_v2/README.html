SFINX 페어 개선 후보 오프라인 재현

Python 3.11.17에서 검증한다. requirements.txt의 버전을 설치한 환경에서 실행한다.

python reproduce.py --output results

기본 명령은 두 페어의 직접 예측과 진입 선별 모델을 과거 입력으로 다시 학습하고, 저장된 예측의 모든 필드 및 42개 계좌의 전체 기록과 비교한다. 결과 폴더는 새 이름이어야 한다. 빠른 계좌 재생만 필요하면 --cached-models를 추가한다.

기존 첫째·둘째 전략의 당시 목표 비중과 고정된 위험 규모를 비교 입력으로 사용한다. 이 명령이 Chronos 기준 모델 전체를 처음부터 재훈련하는 것은 아니다. 입력·소스·원래 결과의 출처와 해시는 manifest.json, provenance.json, expected.json에 기록돼 있다.

reference는 기준시장 과거 자료와 모의 비용·거래량 제약을 사용한다. par와 par_extended는 별도 대회 시장 캔들 자료다. 재사용 과거 구간을 독립 검증으로 표시하지 않는다. 종료 시 미청산 평가손익을 포함하며 원장·잔량은 결과에 남는다.

실제 수신 호가 운용 어댑터의 소스도 포함했다. 미래 비교 계획은 원래 작업공간에 별도로 고정돼 있으며 이 묶음은 예약 원자료를 포함하거나 읽지 않는다. 실거래·서명·배포 명령은 제공하지 않는다. 공식 최종 제출 형식에 대한 주최 측 안내를 대체하지 않는다.
